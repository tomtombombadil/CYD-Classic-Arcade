Load ROMs

Send your MAME ROM zips to a CYD Classic Arcade board over its USB cable. Works on every board - no SD card needed.

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

Load your ROMs

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or a Chromebook). Sending to the board needs the browser to reach USB.
  2. Open USB Transfer on the board: tap the gear, then Settings > USB Transfer (or press Select on a controller). The board only listens for ROMs while that page is open; leave it when they're in.
  3. Plug in the board with a USB cable that carries data. Close anything else using the board's port first: a serial monitor, the installer, or this page in another tab.
  4. Pick your ROM zips: the zips as MAME has them, no unzipping.

    Nothing is sent yet. This page first reads the list inside each zip to see what is there.

    Your files never go to the internet, only down the USB cable. (For a folder, Chrome asks whether to "upload" it: that only lets this page read it.)

      The board's log
      
  
      Something went wrong on the board? Its log says what happened: each start, the games played and their speed, controllers, crashes. With Settings > USB Transfer open on the board, this saves the whole log on this computer as a text file to send to the developer.
      
  
      
  
      

  
      Good to know
      
  
        
    
      • Which zips? The standard MAME sets of the games you own. The chips inside are recognised by their checksums, so any MAME version's zips work. The list of sets says which ones.
        • 
    
      • Pac-Man needs Puck Man's zip when your collection is "split": pacman.zip then only holds what differs from puckman.zip. Pick both; this page tells you when a game is missing chips.
        • 
    
      • Room on the board: about 1.7 MB of zips. Sending the same zips again uses no extra room: they are skipped. To start fresh, tick "Replace the ROMs already on the board".
        • 
    
      • Or use the SD card: any board also takes the zips from a CYD-Classic-Arcade folder on its SD card, copied in when it starts.
        • 
    
      • No answer from the board? Check that its USB Transfer page is open (Settings > USB Transfer, CYD Classic Arcade v0.16.0 or newer - install page), that nothing else has the port open, and on Windows that the CH340 USB driver is installed.
